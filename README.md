# Rotean

**Your life, intelligently managed.**

Rotean is a personal life operating system. It connects time, responsibilities, goals, routines, preferences, memory and context so the user can decide what makes sense to do next.

## Phase 1 foundation
- Expo + React Native + TypeScript
- Expo Router
- Supabase
- Zustand for local UI state
- TanStack Query for server state
- Domain-first feature structure
- Intentional design system
- AI provider isolated from UI code

## Product principles
1. Context before commands.
2. Recommendations before dashboards.
3. Human language over system jargon.
4. Calm interfaces over visual noise.
5. Deterministic rules for dates, scheduling and permissions.
6. AI interprets and reasons; application services own state changes.
7. Every feature contributes to the user's life model.
