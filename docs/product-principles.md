# Rotean product principles

1. Rotean should understand before it advises.
2. A recommendation must have a reason grounded in the user's context.
3. Free time is a first-class part of life, not empty calendar space.
4. Rest is a valid recommendation.
5. The user remains in control; autonomy is earned through explicit permissions.
6. Memory should be useful, reviewable and correctable.
7. The system should adapt instead of punishing missed plans.
8. AI is an implementation detail. Rotean's identity is the life model and the decisions it enables.
9. Do not manufacture certainty. If context is incomplete, say so or ask one useful question.
10. Every screen should answer a human need, not demonstrate a feature.
